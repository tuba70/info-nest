# InfoNest — Research Library UX Case Study

**Enhancing research efficiency through a seamless digital library experience.**

InfoNest is a mobile research library concept designed to help researchers, students, and professionals discover, save, and organize academic resources in one place.

## The problem

Research materials are spread across journals, articles, papers, and webinars. People can lose time switching between platforms, finding credible sources, and organizing saved material.

## Design goal

Design a clear, research-focused mobile experience that makes discovery and resource organization easier.

## UX process

The case study documents a user-centered design process:

- **Understand:** user research, interviews, and competitor analysis.
- **Define:** user personas, an empathy map, and a user journey.
- **Ideate:** user flows and information architecture.
- **Design:** wireframes, high-fidelity screens, and a prototype.
- **Review:** feedback and future design considerations.

The case study also describes quantitative research through surveys, usage analysis, and A/B testing. Add specific study details or results if you have them available.

## Key features explored

- Search and category-based exploration
- Recommended books, articles, and research papers
- Advanced filters and AI-assisted search
- A saved library with collections and bookmarks
- Citation tools and webinar integration
- A personalized dashboard

## Design system

- **Typography:** Poppins
- **Visual direction:** warm, academic-inspired colors with a simple mobile navigation pattern
- **Palette shown in the case study:** `#0C0802`, `#98958F`, `#87590E`, `#F7CF8D`, `#FDE8C7`, `#FFFBF5`
